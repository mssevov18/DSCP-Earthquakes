This project is used to visualise data from NIED's datasets.

# Usage 
### Command usage
`python -m scripts.eq_viewer <event|multi-event> <rootDirectory>`

If you want to view a single event, use the `event` parameter and as the `rootDirectory` paremeter, give it the path of the folder of the event that you have downloaded.

If you want to be able to browse multiple events, use `multi-event` as a second parameter and give `rootDirectory` the path to the folder where you have stored multiple events.
